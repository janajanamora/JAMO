# Cai Header Bar (SillyTavern / TauriTavern Extension)

为 SillyTavern / TauriTavern（iOS）提供 1:1 仿 Character.AI 风格的顶部标题栏：

- **左侧 `<`**：当前有抽屉打开时一键返回聊天；在聊天界面时点击打开角色列表。
- **中间 `[头像] 角色名`**：实时显示当前对话角色（或群聊）的圆角方头像与名称，点击可打开角色面板。
- **右侧 `⋯` / `×`**：一键展开/收起 SillyTavern 原生 9 图标工具栏，所有设置抽屉完整可用且无遮挡。

## 安装方式（通过 GitHub）
1. 将本目录推送到你自己的公开 GitHub 仓库（例如 `https://github.com/你的用户名/ST-Cai-Header`）。
2. 在 TauriTavern / SillyTavern 中打开 **扩展（Extensions）→ 安装扩展（Install Extension）**。
3. 粘贴你的仓库 URL 并确认安装，刷新即可生效。
4. 如需临时关闭或隐藏头像，可在 **扩展 → Cai Header Bar** 中直接开关。
